# Internal GitLab Wiki structure

The repository and GitHub Pages contain stable user documentation. The internal GitLab Wiki should contain living operational material:

- Onboarding and access request procedures;
- DIAL VPN and Token troubleshooting;
- ELITEA Token and maintenance status;
- Azure permissions and Speech Resource troubleshooting;
- Office COM, FFmpeg, and Windows policy runbooks;
- Provider quota/usage notes;
- CI/CD and release runbooks;
- Known issues and temporary workarounds;
- Architecture decisions and test matrix.

Do not put Tokens, credentials, raw logs, or generated product media in the Wiki.
